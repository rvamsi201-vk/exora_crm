Everyone who can sign in to this CRM comes from Nomi. Add a person there and they appear here within the hour, with the password they already use and the role their Nomi organisation membership gives them — an admin in Nomi is an admin here, a member is a salesperson.

Removing someone in Nomi disables their access here on the next sync, while leaving their calls, notes and activity intact.

GAP BOOST RULES
Bonus points added when a gap is detected on the leads' website
How gap detection works
CRM / Enquiry
Scans for HubSpot, LeadSquared, Zoho, Meritto scripts in webpage code
Fee Payment
Looks for Razorpay, Paytm, Stripe, PayU payment gateway scripts
Mobile App
Checks for Play Store / App Store links in the page
HTTPS / SSL
Checks if the website URL uses HTTPS or not
LMS
Scans for Moodle, Canvas, Teachable, LearnPress etc.
Live Chat
Detects Tawk.to, Tidio, WhatsApp, Zendesk, Freshchat
Admission Portal
Looks for keywords: "apply online", "registration form"
ERP / Attendance
Detects Fedena, Entab, MyClassboard, SchoolPad
Limitation: Only the direct public website is scanned. If a tool is used internally (separate app/portal not embedded in the website), it won't be detected. Gap = "not found on website" not "doesn't exist".
